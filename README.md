# Calculadora de Média Universitária 🎓🐱

Este projeto é uma calculadora interativa desenvolvida em **Python** com **Streamlit**.  
Ela permite:
- Calcular a média final dos bimestres.
- Mostrar quanto o aluno precisa tirar para ser aprovado, considerando a média mínima da universidade.
- Exibir um gráfico de barras comparando as notas.
- Interface estilizada com paleta personalizada.

## 🚀 Como rodar
1. Clone este repositório:
   ```bash
   git clone https://github.com/Livia-Oliveira231964/calculadora-nota-faculdade.git
2. Instale as dependências:
   ```bash
   pip install -r requirements.txt
3. Execute o app:
    ```bash
   streamlit run app.py

## 📦 Dependências- Python 3.11+
* Streamlit
* Altair
* Pandas
